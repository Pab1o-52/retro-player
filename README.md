# 🎮 Retro Player Web

[![Deploy Status](https://img.shields.io/badge/Deploy-GitHub_Pages-success)](https://Pab1o-52.github.io/retro-player/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Retro Player** — это современный браузерный эмулятор ретро-консолей (NES, SNES, Sega Mega Drive), написанный на React и TypeScript с использованием WebAssembly-движка [Nostalgist.js](https://github.com/retroarch-web/nostalgist.js) (ядра RetroArch). 

Играйте прямо в браузере на ПК или смартфоне, скачивайте игры из встроенного каталога, настраивайте управление под себя и играйте с друзьями по сети (P2P)!

🚀 **Сайт проекта:** [https://Pab1o-52.github.io/retro-player/](https://Pab1o-52.github.io/retro-player/)

---

## ✨ Главные особенности

* **🏛️ Встроенный каталог Archive.org:** 
  * "Топ 100" отборных игр (с оригинальными обложками из базы Libretro).
  * Полноценный браузер архивов для NES, SNES и Sega с бесконечным скроллом.
  * Прямая загрузка игр в оперативную память прямо с серверов Архива Интернета (без проблем с авторскими правами на хостинге).
* **🕹️ Поддержка трех платформ:** 
  * Nintendo (NES / Dendy)
  * Super Nintendo (SNES)
  * Sega Mega Drive / Genesis
* **📱 Идеально для смартфонов (PWA-ready):**
  * Плавающий «аналоговый» 3D-джойстик (тап и тяни) или классическая крестовина (D-pad).
  * 📌 **Редактор раскладки:** Кнопки и крестовину можно свободно перемещать по экрану и менять их размер под свои пальцы.
  * Выбор количества кнопок (2, 3, 4, 6) в зависимости от приставки.
  * Вибрация (Haptic Feedback) при нажатиях.
* **💾 Офлайн-библиотека и сохранения:** 
  * Сохранения прогресса (Save States) и загруженные игры остаются в памяти вашего браузера (IndexedDB).
  * Автоматическое извлечение ZIP-архивов.
* **⌨️ Поддержка ПК и клавиатуры:** 
  * Гибкая настройка биндов клавиш для каждого действия (WASD, стрелочки и т.д.).
  * Полноэкранный режим.
* **🌐 Сетевой Мультиплеер (Netplay P2P):** 
  * Создайте игру в 2 клика и отправьте ссылку другу.
  * Работает через WebRTC (PeerJS).
  * **Авто-синхронизация ROM'а:** если друг подключается, игра автоматически скачивается на его устройство с вашего!

## 🛠️ Технологический стек

* **Frontend:** React 18, TypeScript, Vite
* **Стилизация:** Tailwind CSS
* **Стейт-менеджер:** Zustand
* **База данных (локально):** LocalForage (IndexedDB)
* **Эмуляция:** [Nostalgist.js](https://nostalgist.js.org/) (ядра: `fceumm`, `snes9x`, `genesis_plus_gx`)
* **Сеть:** PeerJS (WebRTC)

## 🚀 Установка и запуск локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Pab1o-52/retro-player.git
   cd retro-player
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```

> 💡 **Примечание:** Сетевая игра и некоторые другие фичи требуют безопасного контекста (HTTPS или `localhost`).

## 🤝 Как добавить свои игры
Вы можете добавить любую игру с вашего компьютера через кнопку 📁 **Файл**. Поддерживаются чистые ROM-файлы (`.nes`, `.sfc`, `.md`, `.gen` и др.) и упакованные `.zip` архивы. Приложение само определит платформу и подберет нужное ядро.
